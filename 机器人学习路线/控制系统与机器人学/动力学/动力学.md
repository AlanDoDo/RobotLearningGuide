基础动力学：拉格朗日方程、牛顿-欧拉方法、质量矩阵、科里奥利力

多体动力学：递归算法、关节扭矩计算、前馈控制

**刚体动力学的欧拉 - 拉格朗日方程**：

$M(q) \ddot{q} ​+ C(q, \dot q​) \dot q​+G(q) = \tau + J^{T} (q) F_{ext}$​

公式各参数通俗解释（机器人工程视角，无需深究推导）：

| 参数                   | 含义                | 物理意义                           |
| -------------------- | ----------------- | ------------------------------ |
| $q,\dot q,\ddot{q}$  | 关节位置 / 速度 / 加速度向量 | 机器人所有关节的运动状态，维度 = 关节数 n        |
| $M(q)$               | 惯性矩阵（n×n）         | 描述机器人全身的惯性分布，与关节位置 q 相关        |
| $C(q,\dot q) \dot q$ | 科氏力 / 离心力向量（n×1）  | 描述关节运动产生的耦合力，随位置 / 速度变化        |
| $G(q)$               | 重力向量（n×1）         | 描述重力对各关节的作用力，与机器人姿态相关          |
| $\tau$               | 关节力矩向量（n×1）       | WBC 的**求解目标**，即每个关节需要输出的力矩     |
| $J^{T} (q)$          | 雅可比矩阵（m×n）        | 接触点（足底 / 末端）的雅可比矩阵，m = 接触点的自由度 |
| $F_{ext}$​           | 外部接触力向量（m×1）      | 机器人与环境的接触力（如足底地面反力、末端操作力）      |

**公式核心含义**：机器人全身的**惯性力 + 科氏力 + 重力**，等于**关节输出力矩 + 外部接触力的关节等效力矩**，建立了 “关节力矩 - 运动状态 - 接触力” 的一一对应关系。

## 全身力控制（Whole-Body Control, WBC）

核心是**在统一的优化框架下，协调机器人全身所有关节的力 / 力矩与位姿，同时满足运动跟踪、力约束、关节限位等多目标要求**，让机器人实现稳定、柔顺、灵活的全身运动（如行走、上下台阶、推物、抗干扰），是区别于传统单关节 / 末端控制的**全维度机器人控制方法**。
