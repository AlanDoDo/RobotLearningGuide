## ROS安装

```
wget http://fishros.com/install -O fishros && . fishros
```

## 测试

运行ROS核心
```ros
roscore
```

例子
```
sudo apt install ros-noetic-rqt-robot-steering
```

运行功能包 控制机器人的速度
```
rosrun rqt_robot_steering rqt_robot_steering
```

安装小乌龟功能包
```
sudo apt install ros-noetic-turtlesim
```

启动小乌龟功能包
```
rosrun turtlesim turtlesim_node 
```

设置话题 `turtle1/cmd_vel`,然后调节滑杆可以控制小乌龟移动


## 创建工作空间

```
mkdir catkin_ws

cd catkin_ws

mkdir src

cd src
```

安装git下载功能包
```
sudo apt install git
```

```
git clone https://github.com/6-robot/wpr_simulation.git
```

查看文件格式
* scripts 目录用于放置脚本文件和Python程序，安装依赖包，为实体机器人映射端口

在~/catkin_ws/src/wpr_simulation/scripts$路径下ls查看脚本文件

使用脚本安装编译需要的依赖库
```
./install_for_noetic.sh 
```

## 回到工作空间编译

在~/catkin_ws目录下运行catkin_make进行编译
```
cd ~/catkin_ws
```

```
catkin_make
```

## 使用source指令载入工作空间的环境设置

```
source ~/catkin_ws/devel/setup.bash 
```

将source指令添加到.bashrc脚本中
```
gedit ~/.bashrc 
```

在文件末尾添加一行
```
source ~/catkin_ws/devel/setup.bash
```
## 使用 roslaunch 运行编译好的ROS程序

```
roslaunch wpr_simulation wpb_simple.launch
```

打开一个新的终端，用速度控制软件来驱使它移动
```
rosrun rqt_robot_steering rqt_robot_steering
```

设置话题`/cmd_vel`，滑动滑杆进行移动测试

## VS Code插件安装及设置

打开vscode，在目录下打开终端输入
```
code ./
```

插件推荐
* Chinese
* ROS(它会顺带安装C/C++和Python)
* CMake

设置编译快捷键 按下`Ctrl + Shift + B`，按下第一个进行编译，再次按下编译快捷键进入catkin_make: build设置，在.vscode增加了tasks.json，修改文件进行自动选择编译

```json
"group": {"kind": "build","isDefault": true},
```

解决头文件报红问题解决办法
1. 进入.vscode中的c_cpp_properties.json进行头尾文件includePath设置
2. 删除c_cpp_properties.json重新启动vscode进行自动初始化

## 超级终端Terminator

```
sudo apt install terminator
```

`Ctrl + Shift + O` 上下分割一个终端
`Ctrl + Shift + E` 水平分割一个终端
`Ctrl + Shift + W` 删除当前的终端
`Alt + ↑ ↓ ← →`      切换焦点终端
