## 用于GMapping自身的参数

### 激光参数
```c
	double maxRange_; //传感器的最大范围。如果传感器范围内没有障碍物的区域在地图中显示为自由空间，则设置maxUrange <实际传感器的最大范围<= maxRange。
	double maxUrange_;//激光的最大可用范围。光束被裁剪为该值。默认值：80.0
	double minimum_score_;//考虑扫描结果的最小分数匹配好。当使用具有有限范围（例如5m）的激光扫描仪时，可以避免在大的开放空间中跳跃姿态估计，分数上升到600+，例如当遇到跳跃估计问题时，尝试50。很重要，判断scanmatch是否成功的阈值，过高的话会使scanmatch失败
	double sigma_;//贪心终点匹配使用的sigma，  默认值0.5
	int kernelSize_;//内核中要查找一个对应关系  默认值1
	double lstep_;//optimize机器人移动的初始值（距离）0.05
	double astep_;//optimize机器人移动的初始值（角度） 默认值0.05
	int iterations_;//扫描匹配器（ICP）的迭代次数  5
	double lsigma_;//激光的sigma值，用于似然计算 0.075
	double ogain_;//评估似然度时使用的增益值，用来消除重采样的影响  3.0
	int lskip_;//每次扫描中要跳过的光束数. 为0,表示所有的激光都处理，尽可能为零，如果计算压力过大，可以改成1

```

### 运动模型的噪声参数
```c
	double srr_;//作为平移函数的平移误差（rho / rho） 0.1
	double srt_;//作为旋转的函数的平移误差（rho / theta）0.2
	double str_;//作为平移函数的旋转中的测量误差（θ/ rho）0.1
	double stt_;//作为旋转的函数的旋转中的测量误差（θ/θ）0.2
```

### 似然采样参数，主要用在scan matching
```c
     double llsamplerange_;//可能性的平移采样范围 0.01
     double llsamplestep_;//可能性的平移采样步骤 0.01
     double lasamplerange_;//角度采样范围的可能性 0.005
     double lasamplestep_;//角度采样步骤的可能性 0.005
```

### 初始化地图直径和分辨率
```c
double xmin_;//初始地图大小X最小值 -100
double ymin_;//初始地图大小y最小值 100
double xmax_;// 初始地图大小X最大值 100
double ymax_;// 初始地图大小y最大值100
double delta_;//地图的分辨率 0.05
```
