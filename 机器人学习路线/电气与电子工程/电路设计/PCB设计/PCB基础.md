## 叠层设计

工具：图层管理器，选择四层板，修改内层名称

我们使用4层板的叠层设计建议如下：

- 顶层-元器件+主要走线
- 中间1-GND
- 中间2-VCC
- 底层-元器件+主要走线

**中间的GND和VCC层不走线，可以提供完整的参考平面，优化信号完整性。**

```JavaScript
四层
SIG－GND－PWR －SIG
SIG－PWR -GND －SIG
六层
SIG－GND－SIG－PWR－GND－SIG
GND－SIG－GND－PWR－SIG －GND
八层
SIG - GND - SIG - GND - PWR - SIG - GND - SIG
```


⭐ **什么是阻抗匹配？**

**阻抗匹配（Impedance Matching）** 让信号从源头（如芯片）传输到负载（如接收端）时，两者的阻抗（对电流的阻碍）相同，信号能量会完全传递过去，不会反射回来。

我们的项目板卡上需要考虑阻抗的线主要有以下几种

- SDIO信号线 单端50ohm ±10%
- MIPI信号线 单端50ohm ±10% 差分100ohm ±10%
- USB信号线 差分90ohm ±10%
- WiFi天线 单端50ohm ±10%

⭐**走线宽度和设计要求**

|   |   |   |
|---|---|---|
|线宽 (mil)|电流 (A)|适用场景|
|6|0.3|主芯片数字信号线|
|10|0.5|其它模块信号（稳压、升压电路等）|
|20|1.3|电源分支、中等电流|
|30|2|主电源、较高电流|
不过值得说明的是，<mark style="background: #ABF7F7A6;">电源相关线</mark>，在空间允许的情况下，其实是<mark style="background: #ABF7F7A6;">越宽越好的</mark>，如果涉及到切换PCB层走线，每 1A 电流最好添加 2-3 个过孔。

## Layout设计规范


我对这类设计规则的理解是，你不能要求每一块板卡都能满足所有设计要求，也不能在背完所有设计规则后才去设计板卡，而是应该边设计边参考，板卡的过程中，多去参考别人的设计，慢慢提升自己的设计过程，当然，一些必须遵循的规则，我们在后面的课程中也会讲解到。

我的习惯是先布要求高的难布的信号线（例如时钟、Mipi、SDIO、音频），然后是电源，接着是其它信号线，最后铺地。

### 晶振

晶振摆放和走线有严格要求，如下：

1. 靠近芯片端摆放，必须与芯片同层，不能过孔
2. 24M晶振走线小于长度400mil
3. 晶振走线和相邻层，用GND屏蔽保护，禁止其它走线

### SPI Flash走线要求

SPIFlash由DATA0、DATA1、DATA2、DATA3、CS、CLK 6根信号线组成。

1. 走线时远离高速信号和干扰源
2. 由于SPI Flash速率不高，走线上没有特别要求

### USB

USB线的走线要求如下：

1. 遵循差分对阻抗 90欧 ±10%规则
2. USB 信号线长度最好在 4000mil 内，我们实际最终距离 1500mil 左右
3. TVS\ESD 器件靠近端子摆放

走线步骤：

1. 设置差分对
2. 设置布线规则

### 音频

**麦克风走线注意点：**

1. 电源要干净——麦克风怕“吵”

如果电源有噪声，麦克风在录音时就会录到“滋滋”的电流杂音。
电源走线要先经过滤波电容，再进入麦克风。

2. 信号线要“短而直”——减少干扰

尽量缩短 MIC 信号线的长度，避免绕大圈。
远离高频信号（比如Wi-Fi、蓝牙天线）和 电源线。

3. 麦克风要不要等长？

低速模拟麦克风：不用太严格。
高速数字麦克风（如PDM）：两根线长度差最好 <5mil（0.127mm），否则可能导致数据错误。

4. 地线设计——别让噪声乱跑

麦克风的地线要“安静”，不能和其他大电流器件共用。
建议：使用 独立地平面 或 单点接地，避免噪声串扰。

5. 让MICXP/MICXN在同一层走线，尽可能不要多层走线

### 升压模块

**背面**最好不要走线和摆放元器件，因为这是会产生干扰的地方，所以要预留好这部分的空间。
